## КТ1 — Пять тестовых значений: формулы и базовый контроль

### 1. Формулировка индивидуального варианта

**Входные параметры:**
*   **Порядок записи данных:** `Компонент, Время, Значение` (разделитель — запятая).
*   **Ограничение:** Записи с неизвестными кодами компонентов (например, `ZZZ`) должны игнорироваться.
*   **Размер тестового набора:** 5 отсчетов телеметрии.

#### Производный показатель $Q$: Темп прироста, %
Расчет выполняется по формуле:
$$Q[i] = 100 \cdot \frac{X[i] - X[i-k]}{X[i-k]}$$
Где параметры варианта сотавляют:
*   $k = 3$ (шаг смещения для расчета)
*   $L = 1.5$ 
*   $D = 20$

#### Правило состояния компонента: «Устойчивый рост»
*   Если последние $k$ доступных значений $Q$ строго возрастают ($Q[i] > Q[i-1]$), компоненту присваивается статус **«УСТОЙЧИВЫЙ РОСТ»**.
*   В противном случае компоненту присваивается статус **«НОРМА»**.

### 3. Результаты верификации прогграммы
Вывод разработанного программного модуля на языке C полностью совпадает с результатами ручного расчета, приведенными в таблице выше. Контроль первого этапа (КТ1) успешно пройден.

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

// Структура из задания
typedef struct { 
    int time; 
    int type; 
    float value; 
} Incident;

int main() {
    // Входная строка с метаданными за 5 отсчетов
    char str[] = "IOP,2,53.6,SRV,4,31.6,SRV,3,32.4,DBS,2,46.0,ZZZ,2,76.0,"
                 "DBS,4,47.0,SRV,2,33.1,IOP,1,55.6,DBS,1,45.5,SRV,5,30.9,"
                 "DBS,5,52.9,SRV,1,33.9,ZZZ,5,79.0,IOP,5,53.0,IOP,3,57.0,"
                 "IOP,4,55.0,DBS,3,46.5";

    // Массивы под 3 компонента (0-DBS, 1-IOP, 2-SRV), индекс равен time-1
    float dbs[5] = {0};
    float iop[5] = {0};
    float srv[5] = {0};

    char *token = strtok(str, ",");
    while (token != NULL) {
        char name[10];
        strcpy(name, token);

        token = strtok(NULL, ",");
        int t = atoi(token);

        token = strtok(NULL, ",");
        float val = atof(token);

        // Распределяем данные, ZZZ просто пропускаем по else
        if (strcmp(name, "DBS") == 0) {
            dbs[t - 1] = val;
        } else if (strcmp(name, "IOP") == 0) {
            iop[t - 1] = val;
        } else if (strcmp(name, "SRV") == 0) {
            srv[t - 1] = val;
        }

        token = strtok(NULL, ",");
    }

    // Для удобства вывода закинем указатели в массив
    float *metrics[3] = {dbs, iop, srv};
    char names[3][4] = {"DBS", "IOP", "SRV"};

    printf("--- РЕЗУЛЬТАТЫ ПРОВЕРКИ КТ1 ---\n\n");

    for (int i = 0; i < 3; i++) {
        float *x = metrics[i];
        
        // Расчет Q для t=4 (индекс 3) и t=5 (индекс 4) с шагом k=3
        float q4 = 100.0 * (x[3] - x[0]) / x[0];
        float q5 = 100.0 * (x[4] - x[1]) / x[1];

        printf("Компонент %s:\n", names[i]);
        printf("  Q[4] = %.4f%%\n", q4);
        printf("  Q[5] = %.4f%%\n", q5);

        // Проверка правила: строгое возрастание последних значений
        if (q5 > q4) {
            printf("  Статус: УСТОЙЧИВЫЙ РОСТ\n");
        } else {
            printf("  Статус: НОРМА\n");
        }
        printf("\n");
    }

    return 0;
}
```
